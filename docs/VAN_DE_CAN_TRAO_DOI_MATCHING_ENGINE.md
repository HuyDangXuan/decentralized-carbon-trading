## 4. Việc của chính Phi chưa xong (không phụ thuộc bên nào)
- Đọc **bài gốc** Chatterjee–Samuelson (1983) và toàn văn Rustichini–Satterthwaite–Williams (1994) (Satterthwaite–Williams 1989 đã đọc).
- Thí nghiệm C đã chạy xong và ghi ở spec §9.5; chưa làm: thị trường nhiều đơn vị mỗi lệnh, m > 16, kiểm chéo bằng thuật toán tìm cân bằng khác.
- Kiểm bằng mô phỏng mức lợi tối đa từ việc tách lệnh dưới largest remainder (spec §5.2).
- Tích hợp `age_prorata`, rollover và API Service vào engine chính (Giai đoạn 3); viết test case theo spec §10 và threat modeling (tuần 5–8).
